# Validation scope — QA14 / MANT05

Scoped emulator and reconstruction validation. The [illustrated report](reports/qa14-native-ui.html)
records direct reading; [UI JSON](evidence/qa14/ui_runtime.json) and
[combat JSON](evidence/qa14/chip_control/runtime.json) contain measured checks.

| Check | Executed scope |
| --- | --- |
| Authority | MANT04 ZIP and both output pairs authenticated/rebuilt before editing; inheritance recorded. |
| Native UI | 21 routes/53 captures per final variant from cold SRAM Continue; later branches use states generated by that same ROM. |
| Navigation | Five PET selections/actions, full carousel cycle and seven SORT selections/actions; original handlers/cursor code retained. |
| SHOP/count | Three choices, insufficient funds, INFO, actual 500 Z purchase, Total Chips 13→14, reentry, save and new-process cold load. |
| Pixel scope | 106 paired final/predecessor captures; zero changed pixels outside declared fields. 51 UI captures match between final variants; two title captures intentionally differ. |
| Saving | Both SRAM copies have valid checksums, agree with each other and same-variant MANT04, and survive cold loading exactly. |
| PET relocation | Native loader traced, expanded bank checked across all five selections and transitions; VRAM writes/resource bounds recorded separately. |
| RC6 | 1,959 functional bytes authenticated, consumed spans including IPS holes protected, zero conflicts. |
| Combat/Y1 | Two inherited synthetic cases, 32 checkpoints per variant against same-variant MANT04: pixel and WRAM equality. AP/SP appears and the player panel restores. |
| Packaging | Inventory, BPS/checksum validation, clean extraction/rebuild/tests recorded in delivery receipt. |

UI routes contain no WRAM edits. Battle setups use named historical synthetic
states, not natural campaign progress. Global WRAM equality is asserted for the
combat checkpoints only. The UI report lists low-RAM differences, including
released stack contents in one reentry checkpoint; graphics buffers differ normally.

The UI seed/core were available here. Private saves and compiled emulator binaries
are excluded; their provenance is in [the dependency record](../maintenance/qa14-dependencies.json).
Public PNG/JSON evidence and replay tools are included. Those private inputs are
needed to repeat emulator routes, but not normal ROM/BPS reconstruction.

Physical hardware, Windows/macOS execution and exhaustive gameplay were not tested.
RC6 remains experimental; original assembly is unavailable. Historical reports keep
their original scope and do not replace this MANT05 evidence.
