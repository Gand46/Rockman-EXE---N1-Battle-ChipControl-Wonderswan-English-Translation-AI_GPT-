5. Cómo trabajar con la entrega

Extraer el ZIP principal y utilizar el contenido de Rockman_N1/ como raíz del repositorio. No añadir el ZIP histórico dentro del árbol de fuentes ni mezclar los dos parches.

python scripts/project.py build --source "/ruta/original.wsc"
python scripts/project.py build --source "/ruta/original.wsc" --variant all
python -m pip install -r requirements/qa.txt
python scripts/project.py verify --source "/ruta/original.wsc"
python scripts/project.py verify-history --archive ../Rockman_N1_Historical_Archive.zip

La compilación por defecto es QA09; Chip Control se solicita explícitamente. El código de entrada y los lanzadores de Windows/macOS se encuentran en scripts/. Las salidas se guardan en build/, excluido de Git y del empaquetado.

6. Alcance y límites conservados

Chip Control continúa siendo experimental. Están presentes sus fuentes de adaptación, pero el material de entrada no contiene las fuentes ensamblador originales de RC6. Tampoco documenta expresamente la autoría/autorización de redistribución de la carga binaria. La reorganización no inventa ni resuelve estas ausencias.

No se afirma una nueva validación en hardware, una partida natural completa o una nueva sesión de emulación. Las comparaciones binarias justifican que esta reorganización no cambió las ROM; no añaden cobertura funcional del juego.

GitHub Actions queda configurado para Linux, Windows y macOS, con permisos de solo lectura y acciones fijadas por SHA. La ejecución remota y la ejecución nativa local en Windows/macOS no se presentan como realizadas. Esta operación no modifica ningún repositorio remoto.

Base documental: archivos suministrados y verificaciones locales conservadas. Criterio de seguridad CI contrastado con documentación primaria de GitHub sobre uso seguro de Actions y permisos de checkout; no se atribuyen licencias nuevas a terceros.
