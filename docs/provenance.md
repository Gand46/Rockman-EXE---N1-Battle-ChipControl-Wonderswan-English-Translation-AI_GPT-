Original localization code, translation manifests, format descriptions and patch
scripts retain the existing [MIT license](../LICENSE), credited to **N1 Battle
translation project contributors** as in the supplied sources. No unsupported list of
individual authors or new relicensing claim is introduced.

Rockman EXE / Mega Man Battle Network, WonderSwan/WonderSwan Color, original sprites,
dialogue, ROM, sound and design remain the material of their respective rights holders.
This is an unaffiliated project. No original or modified commercial ROM is bundled.

The inherited graphics references credit **Metroid345 — MegaMan BN6 Menu**.
The David Fens / FontStruct `Mega-Man-Battle-Network.ttf` mentioned historically is
not redistributed and is not a build dependency. Credit text in original source
comments, data and archived documents is preserved.

The source-only emulator under `components/qa09/qa/emulator/` retains its own
`COPYING`/license files. Its material is not relicensed as MIT and no compiled core is
included. The official-reference table and game-derived resource fragments have
separate provenance; see the original report and migration ledger.

## Optional RC6 limitation

The supplied WonderSwan RC6 release contains IPS/reference evidence, but lacks the
original editable assembly and the builder/tests named in its README.
The source archive listing is retained in
`components/chip-control/provenance/SOURCE_ARCHIVE_MANIFEST_RC6.json`.
The **new adapter** is source code; the **RC6 engine payload** is not source-complete.

The supplied material does not establish an RC6 author or explicit redistribution
permission. This is a documented absence of evidence, not a finding that distribution
is unlawful. Do not attribute this WonderSwan-specific payload to the separate Prof9
GBA project merely because the name is similar. Obtain correct attribution/permission
before public redistribution of the optional vendor IPS or derived BPS.

See [publication checklist](publication.md). All input-file identities, moves and
retained original versions are tracked in `maintenance/migration.json`.
